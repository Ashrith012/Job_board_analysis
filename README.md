# 💼 Jobs Board Analysis 2025 Dashboard

## 📌 Overview

The Jobs Board Analysis 2025 Dashboard is a Power BI project designed to analyze job market trends, hiring patterns, salary distributions, and industry demand across various roles. The dashboard provides valuable insights for job seekers, recruiters, HR professionals, and business leaders to understand the evolving employment landscape.

---

## 🎯 Project Objectives

- Analyze job postings across industries and locations.
- Identify the most in-demand skills and job roles.
- Track hiring trends and recruitment patterns.
- Evaluate salary distributions across different positions.
- Provide actionable insights into the 2025 job market.

---

## 🛠️ Technologies Used

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- Data Visualization

---

## 📊 Dashboard Features

### Executive Overview
Provides a high-level summary of:

- Total Job Postings
- Total Companies Hiring
- Total Job Categories
- Average Salary
- Most In-Demand Roles
- Hiring Trends

### Job Market Analysis
- Job postings by industry
- Job postings by location
- Company-wise hiring activity
- Employment type analysis

### Skills Analysis
- Most demanded technical skills
- Most demanded soft skills
- Skill frequency analysis
- Industry-specific skill requirements

### Salary Insights
- Average salary by role
- Salary distribution by industry
- Salary comparison across locations
- High-paying job categories

### Interactive Filters
Users can explore data using:

- Job Role
- Industry
- Company
- Location
- Experience Level
- Employment Type

3. Refresh the dataset if required.
4. Explore the dashboard through interactive filters and slicers.
